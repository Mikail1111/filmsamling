# Filmsamling

Et CRUD-program til en filmsamling – 1. semester, datamatiker, EK.

## Gruppen

| Fornavn | GitHub |

## Funktioner
Vi kan oprette, vise, søge, redigere og slette film
Vi kan se hvornår en film sidst blev set
finde film, gemme dem og indlæse dem (ved hjælp af csv)
vise film alfabetisk
sortere efter forskellige elementer
og se om der er en ugyldig input


## Struktur
Projektet er delt op i 3 packages (mapper)

1. Vores Userinterface i ui (menu og brugerinput)
2. Movie, MovieCollection, Controller, SortField og Comparator
3. FileHanlder i datasource som indlæser og gemmer film
